# 2026-10-27/28 — pipelined AHB, IHP SG13G2, timing, open-source-only flow

Branch `perf/pipelined-ibus`, merged into `main`. Each step is a tag.

## v0.2-ibus-pipe — pipelined instruction fetch

- New `rv32im_ahb_fetch`: the AHB-Lite address phase for the next PC overlaps the data phase
  of the current one, giving one fetch per cycle from a zero-wait slave.
- `hazard_unit` rewritten: only `bus_stall` freezes the whole pipeline. Everything else is a
  front-end stall plus a bubble.
- IPC up to ≈ 0.8 (`perf_alu_chain` 3106 → 779 cycles).

## v0.3-dbus-pipe — pipelined DBUS/SBUS

- New `rv32im_ahb_dport` (replaces `rv32im_ahb_bridge`). The address phase is issued from EX
  and the data phase is MEM, so loads and stores to a zero-wait slave do not stall.
- LSU and `addr_decode` moved to EX. Store data goes through EX/MEM. A request is presented
  only while the other data bus is ready (keeps `bus_stall` off the address decode).
- `loadstore` 68 → 36, `perf_loadstore_loop` 524 → 330 cycles.

## v0.4-ihp-sram — SoC memories on IHP SG13G2 SRAM macros

- `torv_ahb_sram` became a zero-wait AHB-Lite wrapper around `RM_IHPSG13_1P_<WORDS>x32`, with
  a one-entry write buffer and read merge. New test `sram_wbuf.S`.
- The testbench loads images into the macro arrays. `PDK_ROOT` is needed for simulation.

## v0.5-timing / v0.6-fwd-reg — slow-corner timing at 10 ns

- Dedicated AGU for load/store addresses; two-cycle `MUL*` (+1 cycle per MUL); Booth
  multiplier; post-global-route timing repair; registered forwarding selects and a single
  pre-selected MEM/WB result.
- Full flow, slow corner: −4.35 → −0.73 ns WNS, 508 → 26 violators. Typ/fast corners and hold
  are met; DRC/LVS/antenna are clean; area −11%.

## v0.7-open-flow — open-source tools only

- Removed the Synopsys flow:
  - `dc/` (Design Compiler, TSMC 0.13 µm);
  - `scripts/vcs_build.sh`, `scripts/dc_build.sh`, `scripts/rv32m_verdi_pli.inc.sh`,
    `scripts/rv32m_emit_open_verdi.sh`;
  - `sim/filelists/verdi_soc.f`;
  - the VCS/FSDB/KDB/DC options in `run_case.sh`, `regress`, `sim/Makefile`, `open_rv.sh`;
  - the testbench FSDB dump.
- `verilator_build.sh` passes `-Wno-ASSIGNIN`, so a stock Verilator 5.x builds the testbench
  without local wrappers.
- `open_rv.sh` uses the distro RISC-V toolchain in `/usr/bin` when no project toolchain
  exists, and reports `PDK_ROOT` and `LIBRELANE_VENV`.
- `open_gtkwave.sh` looks in `build/sim/soc/` (it used `build/sim/core/`).
- `make -C librelane flow` (full RTL-to-GDS + signoff). `qor.py` reports signoff results.
  The default `CLOCK_PERIOD` is 10 ns.
- Documentation rewritten for the current code: README, `docs/open_source_flow.md` (new),
  spec, simulation/regression/test READMEs, address map, TODO.
